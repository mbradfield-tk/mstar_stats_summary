mstar_stats_summary - CLI usage
===============================

Steady-state summary of all variables tracked in an M-Star Stats folder.
Scans every tab-delimited stats file recursively (e.g. Fluid.txt,
MovingBody_*.txt, ControlVolume_*/FieldData.txt), determines a single
steady-state start time, and writes a CSV with the steady-state average
and standard deviation of every variable. Optionally writes interactive
HTML plots.

SYNOPSIS
--------
    python mstar_stats_summary.py CASE [options]

ARGUMENTS
---------
    CASE                M-Star case directory, a directory containing a
                        Stats/ folder, or the Stats directory itself.
                        With --batch: a parent directory whose subfolders
                        are individual cases.

OPTIONS
-------
    --batch             Treat CASE as a parent directory and process every
                        case found below it, at any depth (e.g. reactor
                        folders each holding sub-cases). A case is the
                        folder holding input.xml/.msb above a Stats folder.
                        Writes one stats_summary.csv per case plus a
                        combined batch_summary.csv (with a leading "case"
                        column = case path relative to CASE) in the parent
                        directory.

    --cases REL [REL ...]
                        With --batch, only process these cases (paths
                        relative to CASE, as in the batch CSV "case" column).

    --output-root DIR   Write all outputs under DIR instead of the case
                        folders, which are then left untouched. With
                        --batch, per-case outputs go to DIR/<case>/ and the
                        batch CSVs to DIR/.

    --time T            User-defined steady-state start time in seconds.
                        Overrides automatic detection.
                        (default: auto-detect from the mean fluid velocity
                        plateau in Fluid.txt)

    --window W          Steady-state detection window in seconds.
                        (default: 1.0)

    --tol TOL           Steady-state tolerance on windowed-mean drift.
                        (default: 0.02)
                        The plateau starts where the mean of each window
                        stops changing by more than TOL against the window
                        before it. In a plateau of at least 10 windows,
                        excursions shorter than one window are tolerated
                        while they make up at most 10% of its samples, so
                        one late fluctuation does not move the start to the
                        end of the run.

    Notes on the Stats files: M-Star's restart snapshots (Stats/run1,
    run2, ...) are ignored, the top-level files hold the full history.
    Rows whose column count differs from the header (a garbled line, the
    half-written last line of a running solve) are skipped with a warning.
    A negative impeller <freq> is a sense of rotation: speed-based results
    (tip speed, Re, Fr, We, Po, blend time) use its magnitude.
    VTK frames of a running solve's current output step (a .vtp/.vti file
    without its closing tag, or a time step not every block has written yet)
    are skipped with a warning. In --batch mode a case that fails (e.g.
    --dispersion without <dx>) is reported and left out; the tables of the
    other cases are still written.
    Of several Stats folders below a case, <case>/out/Stats is used, else
    <case>/Stats, else the shallowest one (never a copy such as
    backup/out/Stats ahead of the case's own).
    Wall time (cumulative) [h] and Iterations [count] are the last row of
    Timing.txt: M-Star's counters run on over restarts. Where the wall time
    counter starts again (drops to less than half) the runs are added; other
    backward steps are ignored with a warning. If the time column goes
    backwards (rows of several solver runs in one file) the largest counter
    values are reported, with a warning.

    Threads: OMP_NUM_THREADS, OPENBLAS_NUM_THREADS and MKL_NUM_THREADS are
    set to 4 when the script starts, unless they are already set in the
    environment (numpy otherwise starts one thread per core).

    --mix-rsd PCT       RSD threshold in % for the mixed-time of scalar
                        tracers; 5% RSD = 95% mixed. Applied to any RSD
                        column in Scalar_*.txt files. The mixed time is
                        when RSD last crosses below the threshold (linearly
                        interpolated), measured from tracer injection
                        (detected as the end of the initial period where
                        the mean concentration is zero). The injection time
                        and mixed time are reported as extra rows in the
                        CSV, and tracer plots get a dotted vertical line at
                        the absolute mixed time. (default: 5.0)

    --means-vars [VAR ...]
                        Variable names (fuzzy-matched, case-insensitive,
                        units ignored) selecting which variables become
                        columns in the wide means CSV.
                        (default: energy dissipation, velocity, vorticity,
                        mixed time, shear, power number, fluid volume,
                        viscosity, density, rotation speed, angular
                        velocity, interfacial area, d32, dispersed
                        fraction, n_drops, cov, coverage, hinze; with the
                        default list, LB
                        variables and Min/Max variants are excluded so
                        only mean values are reported)

    --output PATH       Output CSV path.
                        (default: <case>/stats_summary.csv; with --batch,
                        the combined batch CSV, default
                        <parent>/batch_summary.csv)

    --plot [VAR ...]    Write one interactive HTML file of plots per stats
                        file. Give variable names (fuzzy-matched, case-
                        insensitive, units ignored) to limit which variables
                        are plotted, or no names to plot all variables.

    --plot-dir PATH     Plot output directory.
                        (default: <case>/stats_plots; ignored with --batch,
                        where plots go to <case>/stats_plots in each case)

    --ref-case CASE     Reference case (exact name or unique substring) for
                        the % differences in the means bar plots.
                        (default: the first case)

    -h, --help          Show help message and exit.

PHASE DISPERSION OPTIONS (Immiscible Two-Fluid)
-----------------------------------------------
    All opt-in. The VTK-based parts (VOF structures, uniformity) need
    pyvista (pip install pyvista); without it they are skipped with a
    warning. New summary rows are tagged in steady_method as interface,
    a(t) kinetics, vof, zonal, S(t) kinetics or hinze. VTK-based rows
    (VOF drops, uniformity, continuity, Hinze) are averaged from
    t_disp = max(flow steady state, a(t) plateau start) and then tagged
    "a(t) plateau" (or "user" with --disp-time) with t_disp in
    steady_start_s. If a(t) never plateaus, t_disp is the start of the
    window the a(t) kinetics fall back to (the last max(--window, 25%) of
    the a(t) trace, never before the flow steady state) and the rows are
    tagged "a(t) (no plateau, last window)"; mass-transfer and assessment
    rows then end in "(a(t), no plateau, last window)".

    --workers N         Processes that analyse the VTK frames side by side
                        (.vtp drop statistics and .vti uniformity); the
                        results are identical to --workers 1. Each worker
                        holds one frame in memory. A frame that fails in a
                        worker, or a worker that dies, ends the case with
                        an error naming the frame. (default: 1)

    --reuse-results RUN_DIR [RUN_DIR ...]
                        Earlier output roots, newest first. VOF-drop and
                        uniformity metrics whose .vtp/.vti files are gone
                        are taken from the first one holding them: the rows
                        (tagged "(reused: <run>)" with the run that computed
                        them) and the per-case CSVs. With --batch the rows
                        of the case in <run>/batch_summary*.csv (else
                        <run>/<case>/stats_summary*.csv), without --batch
                        <run>/stats_summary*.csv. Everything else is
                        recomputed. With --gas-liquid the same holds for
                        the local estimate (gas_liquid_surface.csv).
                        (default with --output-root <...>_dispersion or
                        <...>_gas_liquid, with or without --batch: the
                        earlier sibling folders of the same kind)

    --no-reuse          Never reuse earlier results.

    --addons-only       With --dispersion/--uniformity/--gas-liquid: write
                        only their outputs, not the base summary, means and
                        settings.

    Multi-GPU output (block0, block1, ...): every block writes the VOF
    surface of its own cells up to the centre plane of the neighbour's
    first cell layer. The two cut rims lie on the same grid edges but not
    at the same places (one block interpolates halo values; measured:
    median 0.07, 99% below 0.34 voxels apart), so rim vertices of different
    blocks within 0.5 voxels are welded and a drop crossing a block seam is
    one closed structure. Only rim vertices on a seam move. Needs scipy;
    without it such drops stay open and are excluded (warning).

    --dispersion        Enable dispersion metrics:
                        - from the interface stats file (name containing
                          "interface"): specific interfacial area
                          a(t) = A_int/V_liq [1/m] and area-based Sauter
                          diameter d32(t) = 6*phi/a [m] (dropped when closed
                          drops carry < 50% of the interface);
                        - dispersion kinetics of a(t): a0 (first sample,
                          flat interface), plateau start t_ss_a, a_ss,
                          interface enhancement E = a_ss/a0, t90/t95 (first
                          time (a - a0)/(a_ss - a0) reaches 0.90/0.95),
                          time constant tau (log-linear fit), plateau CoV
                          = std(a)/a_ss and the time integral of a from
                          t = 0 [s/m]. Warns if a(t) never plateaus
                          (extend the run) or a(t) starts late;
                        - from the Volume VOF Surface .vtp files (name
                          containing "VOF" but not "structure", Slice
                          outputs excluded), Immiscible Two-Fluid only
                          (needs 'Fluid N (name) Volume' columns in
                          Fluid.txt; skipped for free-surface cases):
                          drops are closed structures with an equivalent
                          diameter of at least the stricter of
                          --min-voxels voxels and --min-d-dx voxel sizes
                          (resolved vs excluded counts are logged). The
                          bulk phases touch the
                          walls/shaft/impeller, are open and are excluded
                          (reported as n_open). Each drop is assigned to
                          the fluid inside it, sampled from the Fluid 1
                          volume fraction in the .vti volume output at the
                          same time (at the drop centroid for drops < 4
                          voxels across; else from the triangle orientation;
                          M-Star orients the normals toward fluid 2). Per
                          fluid: n_drops, d32 = 6*sum(V)/sum(A), d32/dx,
                          d10, d43, largest drop diameter and
                          F_disp = V_drops / V_fluid (fluid volume from
                          Fluid.txt). Plus the interface coverage
                          A_drops/A_int: the share of the interface-file
                          area carried by closed drops, i.e. how much of
                          the dispersion the drop statistics describe.
                          Frame times come from the 'TIME' field data,
                          else from the filename;
                        - with --sigma and --rho-continuous: the Hinze
                          resolution check (see --hinze-c).
                        Needs the voxel size: --voxel-size, or <dx> from
                        the case's input.xml.

    --dispersed-fraction PHI
                        Dispersed-phase volume fraction (0 < PHI < 1); the
                        area-based d32 is skipped without it. Also used
                        for the Hinze holdup correction (default there:
                        minority volume fraction from Fluid.txt).

    --disp-time T       Start time [s] for the VTK-based dispersion and
                        uniformity metrics, overriding t_disp.

    --area-column NAME  Interfacial area column (fuzzy) in the interface
                        stats file. (default: the first column containing
                        "area"; a warning lists them if there are several)

    --vessel-diameter D Vessel diameter [m]; a warning is issued if a0
                        differs by > 25% from the flat-interface estimate
                        pi*D^2/4/V_liq.

    --liquid-volume M3  Liquid volume [m^3] for a = A_int/V_liq.
                        (default: 'Fluid Volume' from Fluid.txt)

    --vof-dir PATH      Directory searched recursively for the VOF surface
                        .vtp files. (default: the case directory; with
                        --batch, a relative path is taken per case)

    --voxel-size M      Lattice spacing [m]. Structures smaller than
                        --min-voxels voxels are dropped as numerical debris;
                        also used for d32/dx and the resolution check.
                        Required with --dispersion unless <dx> is found in
                        input.xml.

    --min-voxels N      Debris threshold in voxels. (default: 8)

    --min-d-dx N        Drops with equivalent diameter < N voxel sizes are
                        excluded as unresolved; the stricter of this and
                        --min-voxels applies. (default: 4)

    --sigma S           Interfacial tension [N/m] for the resolution check.

    --rho-continuous RHO
                        Continuous-phase density [kg/m^3] for the
                        resolution check.

    --hinze-c C         Constant in the Hinze maximum stable drop size
                        d_max = C*(1 + K_PHI*phi)*(sigma/rho_c)^0.6
                        *(EPS_RATIO*eps)^-0.4, with eps the
                        steady mean energy dissipation rate [W/kg] from
                        Fluid.txt (or --eps-file). Resolved eps excludes
                        subgrid dissipation, so d_max is an upper estimate.
                        d_max/voxel size is reported; below 5
                        a warning is issued that DSD/d32 reflect the grid
                        scale (the specific interfacial area and holdup
                        stay meaningful). (default: 0.725)

    --k-phi K           Holdup (coalescence) correction factor. (default: 0)

    --eps-ratio R       Local/mean eps ratio, e.g. impeller region.
                        (default: 1)

    --eps-file FILE     Stats file (path or name fragment, e.g. an impeller
                        ControlVolume) to take eps from. (default: Fluid.txt)

    --uniformity        Zonal CoV and vertical holdup profile of the phase
                        fraction from the 3D Volume .vti output (array name
                        containing "vof", "phase" or "fraction"; a "solid"
                        or "flag" array, if present, masks non-fluid
                        voxels where nonzero, else voxels where the
                        'Fluid N ... Volume Fraction' arrays sum to < 0.5
                        are treated as solid; BoundaryConditions output
                        is ignored). phi is averaged into
                        axial x radial zones before the volume-weighted
                        CoV = std/mean is computed. With two 'Fluid N ...
                        Volume Fraction' arrays (Immiscible Two-Fluid), the
                        CoV and holdup profile are reported for each fluid,
                        plus the segregation index S = std/sqrt(mean*(1 -
                        mean)) (0 homogeneous, 1 fully segregated), the
                        homogeneity time t_S (S within 5% of its plateau)
                        and, with scipy, the largest connected region share
                        of phi_k > 0.5 per fluid and the continuous phase
                        (share > --continuous-threshold; a warning flags a
                        change after t_disp, i.e. phase inversion).

    --zone-scales NZxNR [NZxNR ...]
                        Zone scales for CoV and S, e.g. 5x2 10x3 20x5.
                        (default: ZONES_Z x ZONES_R, i.e. 10x3)

    --continuous-threshold F
                        Largest-region share above which a fluid is
                        continuous. (default: 0.9)

    --zones-z N         Number of axial zones. (default: 10)

    --zones-r N         Number of radial zones. (default: 3)

    --vertical-axis {x,y,z}
                        Vessel axis / vertical direction. (default: y,
                        M-Star's up direction)

    --axis-center A B   Vessel-axis position in the two horizontal
                        coordinates (x z for a y axis).
                        (default: domain center)

GAS-LIQUID MASS TRANSFER OPTIONS (Free Surface)
-----------------------------------------------
    Liquid-side mass transfer through the free surface: the specific
    free-surface area a = A/V_liq and estimates of kL and kLa. The case
    must be run with M-Star's free-surface model (<fluidModelType> 2 in
    input.xml); any other case fails with a message (with --batch the
    other cases are still processed). Sparged or entrained gas below the
    grid is not part of the estimate.

    --gas-liquid [free-surface]
                        Switch the estimate on. free-surface is the only
                        route: transfer through the free surface alone.

    --gas-diffusivity M2S
                        Diffusivity D of the dissolved gas in the liquid
                        [m^2/s]. Required.

    --gas-nu M2S        Kinematic viscosity of the liquid [m^2/s].
                        (default: input.xml)

    --renewal-length M  Length L a liquid element travels along the surface
                        before it is replaced: Higbie contact time
                        t_c = L / u_s. (default: half the tank diameter)

    --gas-no-local      Skip the local estimate from the VTK output.

    Also used: --liquid-volume, --area-column, --vof-dir, --voxel-size,
    --workers, --reuse-results / --no-reuse, --addons-only.

    kL models (Sc = nu / D):
        Lamont-Scott        0.4   (eps nu)^(1/4) Sc^(-1/2)
        Kawase-Moo-Young    0.301 (eps nu)^(1/4) Sc^(-1/2)
        Kastanek            1.13  (eps nu)^(1/4) Sc^(-1/2)   (Higbie with the
                            Kolmogorov time (nu/eps)^(1/2) as contact time)
        Calderbank-Moo-Young rigid surface
                            0.13  (eps nu)^(1/4) Sc^(-2/3)   (surface held
                            immobile by surfactants: lower bound)
        Higbie              2 (D / (pi t_c))^(1/2), t_c = L / u_s
        Thomas              Sh = kL D_imp / D = 0.19 Re^0.8 Sc^(1/3),
                            Re = u_s D_imp / nu
        Surface divergence  0.5 (D beta_rms)^(1/2), beta = divergence of the
                            velocity in the plane of the surface (VTK only)

    Each model is evaluated on up to three bases, named in the variable:
      "bulk dissipation"      eps = impeller power / liquid mass, P/(rho
                              V_liq), at every Stats sample (without a torque
                              record: the resolved mean of Fluid.txt)
      "surface mean (Stats)"  the surface means M-Star writes to
                              Interface.txt for the fields of the VOF surface
                              output: 'EDR Mean' (dissipation models) and
                              'Velocity Mean' (Higbie, Thomas)
      "local (VTK)"           the fields of the Volume .vti 1.5 voxels below
                              each triangle of the VOF surface, integrated
                              over it: kLa = (1/V_liq) sum kL_i dA_i. When the
                              Volume output is written less often than the VOF
                              surface (fewer than half of its frames), the
                              point data on the surface is used instead.
    kLa = kL a with a = A/V_liq (A from Interface.txt, or the area of the
    VOF surface for the local estimate).

    Grid assessment (gas_liquid_assessment.csv, rows "gas-liquid
    assessment"), with eps_s = dissipation at the surface (local value,
    else the Interface.txt mean, else the bulk value):
      Kolmogorov scale eta_s = (nu^3/eps_s)^(1/4); a DNS of the surface
      turbulence needs dx <= 2.1 eta_s
      Batchelor scale eta_B = eta_s Sc^(-1/2)
      concentration film delta_c = D/kL (Lamont-Scott at eps_s = 2.5 eta_B);
      resolved with 10 voxels across, so dx <= delta_c / 10
    each with the refinement dx / dx_required, the lattice cost factor
    refinement^4 and the number of cells; plus capillary length / dx,
    Hinze bubble size at eps_max / dx, the closed structures of the VOF
    surface, and the blend-time correlation against t90 = ln 10 / kLa.

EXAMPLES
--------
    # Free-surface kLa of a hydrogenation (H2 in the solvent), add-on only
    python mstar_stats_summary.py case --gas-liquid free-surface \
        --gas-diffusivity 1.5e-8 --addons-only --output-root results

    # Auto-detect steady state and write <case>/stats_summary.csv
    python mstar_stats_summary.py test

    # Use a fixed steady-state start time of 5 s
    python mstar_stats_summary.py test --time 5.0

    # Plot all variables (one HTML per stats file)
    python mstar_stats_summary.py test --plot

    # Plot only selected variables (fuzzy name match)
    python mstar_stats_summary.py test --plot "mean velocity" "power number"

    # Custom detection settings and output locations
    python mstar_stats_summary.py test --window 2.0 --tol 0.01 \
        --output results.csv --plot --plot-dir my_plots

    # Bulk-process every case subfolder under runs/
    python mstar_stats_summary.py runs --batch

    # Phase-dispersion metrics with resolution check and plots
    python mstar_stats_summary.py case --dispersion --dispersed-fraction 0.2 \
        --voxel-size 5e-4 --sigma 0.05 --rho-continuous 998 --plot

    # Spatial uniformity of the phase fraction
    python mstar_stats_summary.py case --uniformity --zones-z 10 --zones-r 3

IMMISCIBLE TWO-FLUID EXAMPLE
----------------------------
    Case: 0.27 L liquid-liquid system with 30 vol% dispersed phase,
    lattice spacing 0.372 mm, interfacial tension 0.03 N/m, continuous
    phase water. The VOF surface and volume output must be enabled in
    M-Star (Output/VolumeVOFSurface/*.vtp; a VOF/phase-fraction array in
    Output/Volume/*.vti for --uniformity).

    # one-time setup
    python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
    source .venv/bin/activate

    # all dispersion metrics, uniformity and plots for one case
    python mstar_stats_summary.py SF-031_EM402_350rpm_0.27L \
        --dispersion --dispersed-fraction 0.3 \
        --voxel-size 3.72e-4 --min-voxels 8 \
        --sigma 0.03 --rho-continuous 998 \
        --uniformity --zones-z 10 --zones-r 3 \
        --plot "mean velocity" "energy dissipation"

    Writes, in the case folder:
        stats_summary.csv      + rows: Specific Interfacial Area, Sauter
                               Diameter d32 (interface / VOF), n_drops,
                               F_disp, Zonal CoV, Hinze drop size / voxel
        vof_structures.csv     per-frame drop statistics
        vof_dsd.csv            per-frame drop diameters
        phase_uniformity.csv   per-frame zonal CoV
        holdup_profile.csv     per-frame phi(z)
        stats_plots/dispersion.html

    # interfacial-area metrics only (no VTK output or pyvista needed),
    # with an explicit liquid volume
    python mstar_stats_summary.py SF-031_EM402_350rpm_0.27L \
        --dispersion --dispersed-fraction 0.3 --liquid-volume 2.7e-4

    # compare all cases of a study; d32, interfacial area, F_disp,
    # n_drops and CoV appear as columns in batch_summary_means.csv/.html
    # (the same --dispersed-fraction is applied to every case)
    python mstar_stats_summary.py TAK-495_EM402_20260824 --batch \
        --dispersion --dispersed-fraction 0.3 --voxel-size 3.72e-4 \
        --sigma 0.03 --rho-continuous 998 --uniformity --plot

OUTPUT
------
    stats_summary.csv   One row per variable: source file, variable name,
                        unit, steady-state average and standard deviation,
                        plus the steady-state start time and detection method.

    stats_plots/        (with --plot) One interactive HTML file per stats
                        file, showing the time course of each variable.

    stats_summary_means.csv
                        Wide table: one row per case, one "variable [units]"
                        column per variable (filtered by --means-vars or its
                        defaults), holding the steady-state mean values.
                        Variables tracked in more than one stats file are
                        prefixed with the file name to keep columns unique.

    stats_summary_means.html
                        Bar plots of the means table: for each variable, the
                        absolute values per case and the % difference vs the
                        first case (reference). Written next to the means
                        CSV (batch_summary_means.html with --batch).

    batch_summary.csv   (with --batch) Combined summary of all cases in the
                        parent directory, with a leading "case" column; each
                        case also gets its own stats_summary.csv.

    batch_summary_means.csv
                        (with --batch) Same wide means table across all
                        cases in the batch.

    stats_summary_gas_liquid.csv, stats_summary_gas_liquid_means.csv
                        (with --gas-liquid; batch: batch_summary_gas_liquid*)
                        The free-surface area, kL and kLa of every model and
                        basis, and the grid assessment.

    gas_liquid_timeseries.csv
                        (with --gas-liquid) Per Stats sample: free-surface
                        area, liquid volume, a, A/A0, bulk dissipation, the
                        surface means of Interface.txt, kL and kLa of the
                        Stats-based models.

    gas_liquid_surface.csv
                        (with --gas-liquid) Per VOF surface frame: triangles,
                        surface area, closed structures (bubbles, droplets),
                        sampled area share, surface dissipation (area mean
                        and the mean effective for kL, <eps^(1/4)>^4),
                        surface speed, rms surface divergence, kL and kLa
                        of the local models.

    gas_liquid_assessment.csv
                        (with --gas-liquid) check, value, unit, assessment,
                        basis: the grid a calculation without a kL model
                        would need, surface and bubble resolution, mixing
                        against transfer.

    vof_structures.csv  (with --dispersion) Per VOF frame: region, open and
                        debris counts, iso-surface / drop / interface-file
                        areas, coverage, and per fluid (suffix _fluid1,
                        _fluid2): n_drops, V_drops, F_disp, d32, d32/dx,
                        d10, d43, d_max.

    vof_dsd.csv         (with --dispersion) Per frame and drop: time, fluid
                        inside the drop, region id, equivalent diameter,
                        volume, area.

    phase_uniformity.csv
                        (with --uniformity) Per frame: mean phi and, per
                        zone scale (suffix _NZxNR), zonal CoV and S (per
                        fluid, suffix _fluid1/_fluid2, for two fluids).

    phase_continuity.csv
                        (with --uniformity, two fluids, scipy) Per frame:
                        largest connected region share per fluid and the
                        continuous phase.

    holdup_profile.csv  (with --uniformity) Per frame: phi averaged over
                        each horizontal voxel layer, phi(z).

    stats_plots/dispersion.html
                        (with --plot and --dispersion/--uniformity) a(t),
                        normalized a(t) with t95, d32(t) from the interface
                        and per fluid, F_disp(t) and n_drops(t) per fluid,
                        coverage(t), CoV(t), S(t), largest region share(t),
                        steady-state DSD histogram per fluid and phi(z, t)
                        heatmap.
